# Relying-Party and Consumer Impact Controls

TSPP v0.11.0 adds controls that make public assurance useful beyond the operator. The controls require discoverability, freshness, limitation disclosure, revocation guidance, redress metadata, consumer impact statements, and audit-ready publication records.

| Control | Purpose |
|---|---|
| TSPP-RP-01 | Public assurance summary discoverability. |
| TSPP-RP-02 | Freshness and validity-window disclosure. |
| TSPP-RP-03 | Relying-party limitation disclosure. |
| TSPP-RP-04 | Revocation and status-check guidance. |
| TSPP-RP-05 | Redress or contact channel metadata. |
| TSPP-RP-06 | Consumer-impact statement. |
| TSPP-RP-07 | Audit-ready publication record. |
