# TRQP-TSPP v0.13.0 Release Notes

## Summary

v0.13.0 is the TSPP portion of the Operational Trust Stack Maturity Release. It positions the repo as a stable posture computation engine with explicit release thresholds, validation evidence, and archive hygiene.

## Highlights

- Added release governance for patch, minor, maturity, and no-release changes.
- Added change-intake criteria for control, profile, posture evidence, validation, and compatibility impact.
- Added release validation documentation for the coordinated Hub v1.8.0 / CTS v1.5.0 / TSPP v0.13.0 tuple.
- Removed generated Python package metadata and OS artifacts from the release archive.
- Refreshed README and roadmap language around high-value, evidence-producing TSPP commits.
- Added a GitHub PR template to require maturity-gate evidence.
