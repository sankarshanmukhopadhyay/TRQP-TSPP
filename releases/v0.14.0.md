# TRQP-TSPP v0.14.0 — Posture Evidence Producer

## Summary

This release makes TRQP-TSPP a governed, reproducible posture-evidence producer for the coordinated TRQP End-to-End Assurance Execution and Evidence Chain.

## Coordinated release tuple

| Component | Version | Role |
|---|---:|---|
| TRQP Assurance Hub | v1.9.0 | Evidence composition and assurance decision |
| TRQP Conformance Suite | v1.6.0 | Protocol conformance evidence |
| TRQP-TSPP | v0.14.0 | Security and privacy posture evidence |

## Added

- Machine-readable `PROJECT-STATUS.yaml` with authority, maturity, intended-use, evidence, and review declarations.
- Posture report generation bound to explicit `run_id` and `target_id`.
- Control-coverage traceability and SHA-256 evidence indexing.
- `make assurance-check` and `make evidence` entry points.
- Cross-stack execution and evidence-consumption guidance.

## Compatibility

This release is additive relative to v0.13.0. Consumers of the existing posture-report contract remain compatible. The coordinated Hub workflow expects v0.14.0 evidence for release set `ots-2026-07`.

## Validation

```bash
make validate
make assurance-check
```

Both commands must pass before tagging.

## Authority and limitations

TSPP owns posture profiles, controls, and posture evidence semantics. It does not own the TRQP protocol specification, Hub assurance decisions, or external certification. Generated repository evidence demonstrates reproducibility and is not independent assurance.

## Upgrade guidance

Pull the release, run `make assurance-check`, and use the generated `artifacts/validation/tspp-report.json` together with the paired CTS report under the same `run_id` and `target_id`.
