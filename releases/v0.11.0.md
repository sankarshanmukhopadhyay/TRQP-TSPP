# v0.11.0 — Relying-Party and Consumer Impact Controls

## Release purpose

This release makes posture evidence useful to relying parties and affected users. It adds publication controls, a relying-party publication schema and example, and harness tests for freshness, limitations, revocation guidance, redress, and consumer impact metadata.

## Highlights

- TSPP-RP-01 through TSPP-RP-07 controls.
- `schemas/core/relying-party-publication.schema.json`.
- Relying-party publication example.
- `test_12_relying_party_controls.py`.
- Cross-repo references refreshed for Hub v1.6.0 and CTS v1.3.0.
